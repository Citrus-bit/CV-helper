## 硬门

- 保持原 PDF 不可变，并拒绝伪装、损坏、加密、超大小、超页数和超资源预算文件。
- 对有效数字 PDF 使用原生文字层；不得无理由调用 OCR。
- 对 mixed 页只补充缺失区域，或在整页 fallback 后可靠去除与原生文字重复的 OCR 块。
- 为每个输出块保留合法页索引、归一化 bbox、`native | ocr` 来源、置信度和唯一稳定 ID。
- 传播取消和 deadline；终止 OCR/worker，不泄漏临时文件、子进程或对象 URL。
- 遵守 Capability 数据范围和网络策略；未经审批不得把原 PDF 或页面图像发送到网络。
- 通过 canonical Schema；失败或 fallback 不得改变 API wire shape 或丢失 warning。
- 不从版面推断候选人事实，不把解析结果描述成已核验事实或 ATS 厂商兼容结论。

## 100 分评分

| 维度 | 分值 | 满分要求 |
| --- | ---: | --- |
| 输入安全与资源边界 | 10 | 所有拒绝路径稳定、可解释且有测试；压缩/像素/字符/区域/并发/时间均有上限 |
| 原生解析保真度 | 20 | 数字页文字、页码、坐标、字体信号和阅读材料高保真；不触发 OCR |
| OCR 选择与质量 | 20 | scan/mixed 决策正确；局部识别、离线模型、低置信 warning 和去重完整 |
| SourceBlock 完整性 | 15 | ID、来源、bbox、置信度、style、顺序与证据引用稳定且 Schema 合法 |
| 分段与阅读顺序 | 15 | 单栏、双栏、标题、列表、联系方式、页脚和表格信号得到可解释处理 |
| 失败、取消与回退 | 10 | 正确区分可恢复与不可恢复错误；`usedFallback`、资源释放和 revision 保持正确 |
| 隐私、可观测性与性能 | 5 | 禁网基线、最小日志、trace、用量和预算证据齐全，不记录正文或 PII |
| 测试与人工验收 | 5 | fixture 矩阵、adapter 等价性、真实 PDF 对照和未覆盖风险均有记录 |

建议候选启用分数设为至少 90/100，同时要求相对 baseline 在主指标上不回退。不要用总分抵消硬门失败。

## Fixture 矩阵

| 样本 | 必须验证 |
| --- | --- |
| 中文单栏数字 PDF | 原生字符、标点、行序、字体层级；OCR 调用数为 0 |
| 英文单栏数字 PDF | 连字符、项目符号、日期和链接文本；OCR 调用数为 0 |
| 中英混合 PDF | 字体切换、空格、专有名词和 locale；不得把相邻文字拼坏 |
| 双栏数字 PDF | 列内顺序优先、跨列切换可解释；歧义产生 warning |
| 表格/侧栏 PDF | 保留 table 或结构风险信号；不得将单元格随机串联为事实 |
| 纯扫描 PDF | 整页 OCR、语言模型可用、低置信提示和页面边界正确 |
| mixed PDF | 原生文字保留、缺失图像内容补入、重复率接近 0 |
| 旋转页 | 检测或明确 warning；不得输出看似正常但顺序错误的高置信结果 |
| 乱码/异常字体 | 降低置信度并提示；必要时局部 OCR，不静默替换全部原生内容 |
| 空页/图片页 | 不生成虚假文字；保持页数和空页信号 |
| 加密/损坏/伪装 | 稳定拒绝，不进入 OCR，不留下临时资源 |
| 资源攻击样本 | 在大小、页数、像素、区域、字符、并发或 deadline 上被限制 |
| 用户取消 | 快速传播 `AbortError`，不执行 baseline 覆盖，不继续 OCR |
| worker 不可用 | 仅对可恢复错误回退 PDF.js，返回兼容结果和明确 warning |

## 指标定义

### 原生字符召回率

按人工真值归一化字符序列计算：

`召回率 = 正确恢复字符数 / 真值字符数`

- 分开报告中文、英文、数字、标点和专有名词。
- 把阅读顺序错误单独报告，不用字符召回率掩盖顺序缺陷。
- 将 ≥99% 视为生产样本目标，不把少量 fixture 通过写成已证明结果。

### OCR 字符准确度

同时报告字符错误率 CER 与召回率：

`CER = (替换 + 删除 + 插入) / 真值字符数`

- 对清晰扫描件以字符召回率 ≥95% 作为候选目标。
- 单独统计数字、百分号、货币、日期、邮箱和技术术语错误。
- 任何数字变化都必须触发人工核对，不因平均 CER 较低而忽略。

### 阅读顺序正确率

按人工标注的相邻块先后关系计算：

`正确率 = 正确相邻关系数 / 标注相邻关系数`

- 对单栏、双栏、跨页、侧栏和表格分别报告。
- 以 ≥95% 作为生产人工抽检目标；复杂版面必须给出置信度与 warning。

### OCR 选择率

分别统计：

- 数字页误 OCR 率：目标 0%。
- scan 页漏 OCR 率：目标 0%。
- mixed 页无效区域 OCR 比例：越低越好，不得以漏识别换取低调用率。
- native/OCR 文本重复率：按规范化文本和空间重叠计算，发布门为 0 个已知回归。

### SourceBlock 健康度

要求：

- 100% ID 唯一且跨确定性重跑稳定。
- 100% 页索引位于合法范围。
- 100% bbox 数值有限、非负且落在归一化页面范围。
- 100% 块声明 `native`、`ocr` 或经用户修正后的 `user` 来源。
- 100% AST 来源引用能解析到现有块。

## Capability 分项验收

### `document.parse` / `eval.document.parse.v1`

- 验证 PDF 签名、页数、摘要、原生块、页面预览和 extraction mode。
- 验证 worker 与 PDF.js 输出语义兼容，而非要求像素级完全相同。
- 验证可恢复 worker 错误回退；摘要不一致、413 和取消不回退。
- 验证未授权 `original_pdf` 时拒绝执行。

### `document.ocr` / `eval.document.ocr.v1`

- 验证只接收获准页面/区域图像，不接收整份 Resume AST 或联系方式。
- 验证模型离线可用、运行时不下载、并发和 deadline 有界。
- 验证低置信、空识别、超输出和子进程失败均有稳定 warning。
- 验证取消后 worker 终止且不返回晚到结果。
- 当前契约 `1.0` 还要求 `engine: "tesseract.js"`；非 Tesseract 候选必须先完成版本化 Schema 迁移，不得谎报引擎来通过校验。

### `document.segment` / `eval.document.segment.v1`

- 验证输入仅为 SourceBlocks。
- 验证每页排序、角色推断、segment 边界和块引用。
- 验证未知标题不会被强行映射为错误的标准板块。
- 验证双栏、表格和页脚歧义不被赋予虚假高置信度。

## 人工预览清单

逐页并排查看原 PDF 与解析覆盖层：

1. 核对姓名、联系方式、公司、学校、日期、数字、百分比和技术术语。
2. 核对项目符号、段落边界、标题层级和跨页条目。
3. 核对双栏阅读顺序、侧栏、页眉页脚和表格。
4. 标出所有 OCR 块并重点检查数字与专有名词。
5. 确认 warning 与真实问题一致，且低置信内容可被用户发现和修正。
6. 记录样本类型、引擎版本、Capability sourceVersion、耗时和已知缺口。

## 回归与替换结论

在评测记录中同时列出：

- baseline 与 candidate 的版本、许可、来源、数据范围和网络策略。
- 每类 fixture 的原生召回、OCR CER/召回、顺序正确率、重复率、耗时和峰值资源。
- 失败、超时、取消、非法输出和 fallback 结果。
- 需要人工核对的样本与误报/漏报。
- `enabled | rejected | evaluating` 结论、feature flag、回滚版本和日期。

若候选只改善某一类扫描件但损害数字 PDF、隐私、取消或 wire shape，保持 baseline 并将候选限制为继续评测。
