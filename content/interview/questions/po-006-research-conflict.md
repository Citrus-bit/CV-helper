# 用户研究相互矛盾 / Conflicting user research

## 问题 / Question
**中文：** 访谈用户强烈要求更多控制项，但行为数据表明大多数人从不修改默认设置。你如何解释并决定下一步？

**English:** Interviewees strongly request more controls, while behavioral data shows most users never change defaults. How would you interpret this and decide next steps?

## 追问 / Follow-ups
- 中文：样本和任务场景可能有哪些偏差？ / English: What sampling or task-context biases might exist?
- 中文：你如何验证“控制感”而非“更多控件”才是真需求？ / English: How would you test whether the need is control rather than more controls?

## 优秀信号 / Strong signals
- 不把定性或定量任一方视为自动真相。 / Does not treat either qualitative or quantitative data as automatically true.
- 检查用户分群、任务频率、提问方式和默认值质量。 / Checks cohorts, task frequency, question framing, and default quality.
- 设计低成本原型区分配置需求与信任需求。 / Uses low-cost prototypes to distinguish configuration from trust needs.

## 评分锚点 / Scoring anchors
- `1`：简单选择相信访谈或埋点。 / Simply chooses interviews or analytics.
- `3`：提出合理解释并补充研究。 / Offers plausible explanations and additional research.
- `5`：识别数据生成机制、形成竞争假设，并用行为实验做决策。 / Examines how evidence was generated, forms competing hypotheses, and tests behaviorally.

## 风险项 / Risks
- 只找支持既定方案的用户。 / Recruits only users who support the preferred solution.
- 将少数高需求用户的意见平均化。 / Averages away a high-need minority.
