# 批量缺陷根因 / Batch defect root cause

## 问题 / Question

**中文：** 客户报告一批产品出现间歇性缺陷，但出厂检验记录正常。你如何围堵、定位根因并验证永久措施？

**English:** A customer reports intermittent defects in a batch despite normal release inspection. How would you contain, find root cause, and validate permanent action?

## 追问 / Follow-ups

- 中文：如何界定受影响批次和追溯边界？ / English: How would you define affected lots and traceability boundaries?
- 中文：怎样证明纠正措施有效且没有新副作用？ / English: How would you prove corrective action works without new side effects?

## 优秀信号 / Strong signals

- 先保护客户、隔离库存并保留样品和过程数据。 / Protects customers, quarantines stock, and preserves samples and process data.
- 区分症状、逃逸点和发生根因，以实验验证。 / Separates symptom, escape point, and occurrence cause and tests them.
- 更新控制计划、失效模式和分层审核。 / Updates control plans, failure modes, and layered audits.

## 评分锚点 / Scoring anchors

- `1`：只增加终检或责怪操作员。 / Adds final inspection only or blames an operator.
- `3`：完成隔离和根因分析，但验证与系统更新有限。 / Contains and analyzes root cause with limited validation or system updates.
- `5`：量化范围、证据化验证根因、实施防错并确认长期能力。 / Quantifies scope, validates cause, mistake-proofs, and confirms sustained capability.

## 风险项 / Risks

- 在根因不明时释放可疑库存。 / Releases suspect inventory before cause is understood.
- 将相关性直接视为根因。 / Treats correlation as root cause.
