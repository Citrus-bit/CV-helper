# 新功能采用率低 / Diagnosing low feature adoption

## 问题 / Question
**中文：** 一个用户访谈中评价很高的新功能，上线后采用率持续偏低。你会如何区分发现问题、价值问题和使用摩擦？

**English:** A feature tested well in interviews but has low adoption after launch. How would you distinguish discovery, value, and usability problems?

## 追问 / Follow-ups
- 中文：你会怎样构建采用漏斗和用户分群？ / English: How would you build the adoption funnel and cohorts?
- 中文：什么时候应改进功能，什么时候应停止投入？ / English: When would you improve the feature versus stop investing?

## 优秀信号 / Strong signals
- 先确认埋点、目标用户和可发现机会是否正确。 / Validates instrumentation, target users, and discovery opportunities.
- 结合行为数据、任务访谈和未使用者研究。 / Combines behavior data, task interviews, and non-user research.
- 用最小实验区分教育、摩擦和价值假设。 / Uses small tests to separate education, friction, and value hypotheses.

## 评分锚点 / Scoring anchors
- `1`：立即加弹窗或推送。 / Immediately adds pop-ups or notifications.
- `3`：分析漏斗并访谈用户，但假设验证不够清晰。 / Analyzes a funnel and interviews users with limited hypothesis testing.
- `5`：验证数据、细分问题、设计区分性实验并设置继续/停止标准。 / Validates data, segments causes, runs discriminating tests, and sets continue/stop criteria.

## 风险项 / Risks
- 用打扰性引导掩盖功能没有价值。 / Uses intrusive prompts to mask weak value.
- 只访谈活跃用户造成偏差。 / Interviews only active users.
