# 销售管道预测 / Pipeline forecasting

## 问题 / Question
**中文：** 团队管道金额充足，但连续两个季度未达成收入预测。你会如何重建预测可信度？

**English:** Pipeline value appears sufficient, yet the team has missed revenue forecasts for two quarters. How would you rebuild forecast credibility?

## 追问 / Follow-ups
- 中文：你会检查哪些阶段退出条件与停留时间？ / English: Which stage exit criteria and aging patterns would you inspect?
- 中文：如何减少销售人员主观乐观而不打击主动性？ / English: How would you reduce optimism bias without discouraging initiative?

## 优秀信号 / Strong signals
- 分析历史转化、周期、单量、滑期和来源质量。 / Analyzes conversion, cycle, deal count, slippage, and source quality.
- 使用客户证据定义阶段，而非销售主观概率。 / Defines stages with customer evidence, not seller confidence.
- 区分 commit、best case 和风险范围，并持续校准。 / Separates commit, best case, and risk ranges and recalibrates.

## 评分锚点 / Scoring anchors
- `1`：要求团队把更多机会填入 CRM。 / Asks the team to add more opportunities to CRM.
- `3`：清理管道并使用历史转化率，但分群和校准有限。 / Cleans pipeline and uses historical conversion with limited segmentation or calibration.
- `5`：重定义证据化阶段、建模不确定性、复盘偏差并改进领先指标。 / Rebuilds evidence-based stages, models uncertainty, reviews bias, and improves leading indicators.

## 风险项 / Risks
- 通过降低预测值掩盖执行问题。 / Hides execution problems by lowering forecasts.
- 以处罚导致团队延迟记录风险。 / Uses punishment that encourages hiding risk.
